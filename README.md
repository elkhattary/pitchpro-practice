# PracticeRoom

PracticeRoom is a small conversation-practice experience built as a take-home exercise inspired by PitchPro.

The app lets users choose a practice scenario, answer three focused questions, receive immediate feedback after each response, and view a final performance report.

## Live Demo

https://pitchpro-practice.vercel.app

## Features

- Scenario selector
- Three-question guided practice flow
- Live word count
- Feedback after every response
- Clarity, relevance, and specificity scoring
- Final performance report
- Loading state during analysis
- Validation for short responses
- Retryable analysis error state
- Multiple practice scenarios:
  - Job Interview
  - Startup Pitch
  - Sales Conversation

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
